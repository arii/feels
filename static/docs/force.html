Extracting Force via Joint Telemetry

The system derives payload characteristics directly from the arm's joint torque telemetry. The pipeline isolates the payload's dynamic response through three direct processing steps:

  • Detrending: a low-pass filter removes gravity and slow pose shifts, isolating the fast, motion-coupled torque residuals.
  • Feature Extraction: the variance, peak-to-peak swing, and phase lag of these residuals form the physical signature. A sloshing liquid produces high residual variance and measurable phase lag, while a rigid weight produces low variance and near-zero lag.
  • Contrast Matching: the system classifies items by contrasting these dynamic features against a taught library, recognizing the unique residual imprints generated by the swirl excitation.

Leveraging Native Sensors

Every servo arm naturally reports joint loads through its motor controllers. By analyzing this existing telemetry channel, the pipeline achieves accurate material classification using the built-in hardware, bypassing the $5k+ cost, wrist integration, and calibration required for an external 6-axis F/T sensor.

Operating Parameters

The architecture is optimized specifically for pattern matching. By filtering out pose-dependent gravity terms, the system isolates motion-based residuals that are highly repeatable and robust when compared within a single fixed macro.
