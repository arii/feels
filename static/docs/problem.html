The formal problem

Setup

A 6-DOF arm holds a lidded, opaque cup. The contents c belong to a set of classes C — empty, water, dish soap, loose candy, a rigid weight — sealed inside the cup. The arm reports joint angles qt and actuator torques τt at 4–5 Hz — the only signals the decision ever sees.

Observation and decision

The robot executes one fixed probing motion (pick up → swirl → place) and records the rollout D = {(qt, τt)}. The task is to map the rollout to a contents label:

ψ: D → ℝ¹⁰        (feature map: time series → 10-D signature)
e = Wz / ‖Wz‖₂      (per-feature scaling + L2 normalization)
ĉ = argmax over taught signatures of cosine(e, eᵢ)

Classification is non-parametric: a new item is learned by storing one embedding — the next query simply finds its nearest neighbors.

The lid is the whole problem

From outside, every class looks identical — a camera sees a cup. The contents only reveal themselves in motion, which is what the system measures.

The confound set

Four contents — solid_150g, water_150g, candy_150g, soap_150g — with mass fixed at 150 g. Mass is identical across the set, so any separation comes from dynamics alone: how the contents move when swirled. That isolation is the claim being tested.

What makes it hard

  • Coarse sensing: 4–5 Hz torque telemetry. The true 5–25 Hz rattle band is above Nyquist — we use what the channel carries.
  • Tare drift: joint-torque baselines wander with pose and temperature; static offsets are unreliable, so the signal must come from motion.
  • Hidden by design: the contents stay sealed, so the only supervision is the label the operator teaches.
Honest limits. Static hold torques carry no payload signal at our pose (verified identical across contents). Everything discriminative comes from the swirl dynamics.
