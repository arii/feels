Classifying Sealed Contents Using Only Physical Interaction

A 6-DOF arm holding a sealed cup uses proprioception to classify its contents (empty, water, loose candy, or a rigid weight). Because the lid visually seals the container and static weights can be indistinguishable, the system relies entirely on active movement to identify the object.

Mapping Swirl Dynamics to a 10-D Signature

The system measures dynamics — how contents move when swirled — to identify them. The robot executes a fixed probing motion (pick up → swirl → place) and maps this directly to a prediction:

Time Series → 10-D Signature: The pipeline converts raw joint torques into explicit physical features.

Normalize: The system scales and L2-normalizes the features.

Vector Search: The algorithm queries the taught library for the nearest neighbor to instantly classify the item.

What Makes Classification Hard

  • Coarse sensing: the arm reports torque telemetry at 4–5 Hz. The 5–25 Hz rattle band sits above Nyquist, so the system uses what the channel carries.
  • Baseline drift: joint-torque baselines wander with pose and temperature. Static offsets are unreliable, so the signal comes from motion.
  • Hidden by design: the contents stay sealed. The only supervision is the label the operator teaches.
  • Static hold torques carry no payload signal at this pose (verified identical across contents). Everything discriminative comes from the swirl dynamics.
