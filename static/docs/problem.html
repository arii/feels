The formal problem

The Setup

A 6-DOF arm holds a lidded, opaque cup. To identify the contents, the system relies entirely on standard joint-torque telemetry.

The contents belong to a set of classes: empty, water, loose candy, or a rigid weight.

Because the lid visually seals the container, the system uses physical interaction to classify the objects.

The Solution: Dynamics

The system leverages dynamics — measuring how the contents move when swirled — to reveal exactly what is inside.

The robot executes one fixed probing motion (pick up → swirl → place). The pipeline maps this directly to a prediction:

  1. Time Series → 10-D Signature: raw joint torques are converted into explicit physical features.
  2. Normalize: features are scaled and L2-normalized.
  3. Vector Search: the system immediately finds the nearest neighbor in the taught library for instant classification.

The confound set

Four contents — solid_150g, water_150g, candy_150g, soap_150g — with mass fixed at 150 g. Mass is identical across the set, so any separation comes from dynamics alone: how the contents move when swirled. That isolation is the claim being tested.

What makes it hard

  • Coarse sensing: 4–5 Hz torque telemetry. The true 5–25 Hz rattle band is above Nyquist — we use what the channel carries.
  • Baseline drift: joint-torque baselines wander with pose and temperature; static offsets are unreliable, so the signal must come from motion.
  • Hidden by design: the contents stay sealed, so the only supervision is the label the operator teaches.
  • Static hold torques carry no payload signal at our pose (verified identical across contents). Everything discriminative comes from the swirl dynamics.
