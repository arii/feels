Bringup

Prerequisites: Python 3.12, a virtualenv, and .env with MONGODB_URI (Atlas IP allowlist must include your machine) and the VIAM_* robot credentials. bash setup.sh creates the venv, installs requirements.txt, and copies .env.example to .env.

Mock bringup (no hardware): FEELS_MOCK=1 python realtime_plot.py --port 8080, then open http://localhost:8080. The dashboard serves the full UI on bundled recordings; a purple MOCK badge marks the mode.

Live bringup: python realtime_plot.py --port 8080. Verify with curl localhost:8080/api/status — atlas_configured reports Atlas reachability and cycle reports the macro state. Teach one item in Mode 2, then run Mode 1 on a mystery cup.
