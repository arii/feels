The Problem

The robot classifies what is inside a sealed cup entirely by touch. Because the lid blocks vision, the arm picks up the cup, swirls it, and identifies the contents by measuring the resulting joint-torque dynamics.

Classifying Without a Force-Torque Sensor

External force-torque sensors add cost and complexity. The system classifies contents from the arm's built-in joint-torque telemetry alone.

What Makes Classification Hard

  • Baseline drift: Temperature changes and subtle pose shifts cause baseline torques to wander over time. Because static offsets are noisy and unreliable, only dynamic motion yields a clean differential signal.
  • No static payload signal: At this pose, resting hold torques are identical across all contents. Every discriminative cue comes from how the mass shifts during the swirl.
