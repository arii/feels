About

Feels teaches a robot to identify sealed-cup contents by feel. The challenge: classify cup contents from applied joint torques alone. The system predicts from joint-torque dynamics and uses MongoDB Atlas Vector Search for online classification of new and existing categories.

What the numbers show

The system reliably detects empty vs nonempty cups on held-out recordings. Full results are on the Prediction page.

Where this goes

This is a proof of concept. But the approach generalizes: any robot arm with joint-torque sensing can build tactile intuition about the objects it handles, without additional hardware. With larger datasets, longer training, and task-specific motions, the same pipeline — physical interaction, feature extraction, vector search — could support picking in warehouses, assistive robots in homes and hospitals, anywhere a robot needs touch as well as vision. The expensive part is the data. Collection has started.

Day one: the team chose the lidded-cup idea, wrote the deterministic swirl macro, and recorded the first experiment matrix — pick, swirl, place, repeated across water, weights, screws, and empty cups. The pipeline ran end to end: torque telemetry → 10-D signature → Atlas vector search → prediction.

Day two: the dashboard, the docs site, the simulated-replay backup mode, and the evaluation bake-offs (hand features vs PCA vs Chronos, kNN vs LDA). The team wrote, tested, and demoed the feature extractor, the vector memory, and the docs site over the two days.
