How the System Predicts

The direction is less hand-coding: the system is moving from hand-engineered features toward learned embeddings. The 10-D hand features below are the current live path; the unsupervised alternatives were baked off against them and are documented here with their measured numbers.

The extractor reads the joint-torque time series and computes the 10-D signature described in Approach — ten physical quantities in three groups, matched in the 7 informative dimensions.

The Taught Library

The library holds the taught signatures — 113 at last count (110 in the vector-space plot; 3 mystery held out), each a 10-D embedding with its label, material, category, and session tag, stored in MongoDB Atlas. Teaching writes a signature; the next prediction searches it. The offline evaluation used an 84/21 train/test split of the recordings.

Three Ways to Decide

Vector search over hand features. The query embedding goes to Atlas $vectorSearch, which returns the nearest taught signatures by cosine similarity. This path powers the vector-space plot and supplies the neighbor list on the decision card. On the held-out set it reaches 24% at the category level.

Shrinkage LDA on the same features. atlas.predict_lda standardizes the 10-D library, fits a shrinkage-LDA classifier in milliseconds, and predicts — refit on every call, so a teach takes effect immediately. This is the live decider. On the held-out set: 52% category, 43% material. The binary empty/nonempty number (86%) is a majority-class artifact — the classifier predicts nonempty for everything.

Learned Embeddings

Two unsupervised alternatives were baked off against the hand features: PCA-10 on raw torque-delta trajectories (43% material, matching hand features) and Chronos foundation-model embeddings (56% on swirl-only data, the best measured). Neither runs live — Chronos needs its own 2304-D index and torch on the venue machine.

What a Prediction Looks Like

A fresh recording comes off the swirl macro. The extractor computes the 10-D signature. predict_lda decides. The decision card shows the predicted category, the material, and the closest taught item — with the measured accuracy (52% category) rather than a per-prediction score, since the LDA probabilities are uncalibrated.
